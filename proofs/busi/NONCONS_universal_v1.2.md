## 2. Proof

Notation: V_s = L^3 sites; plane-wave one-particle states |A, +, p, s> with positive-band spinors u_A(p) normalized u^dagger u = I_2 (two spin labels s), momenta p in (2 pi / L a) Z^3 mod 2 pi/a. A trigonometric polynomial of degree <= R in a variable theta means a finite sum of e^{i n theta}, |n| <= R.

### Lemma 0 (locality: one large torus decides all)

Let C = sum_x c_x be translation invariant with c_0 supported within lattice distance R of site 0, support diameter D <= 2R, and coefficients independent of L. Then C = 0 on one torus with L > 2D (so L > 4R suffices) implies C = 0 on every torus with L > 2D and on the infinite lattice (as the family of local terms: the stripped amplitudes vanish identically). [Repair (a): v1 stated L > 2R, which is false; eliminating the momentum-constrained leg doubles the degree, as both checks noted.]

Proof. Fix a sector with n annihilated and n' created legs. The matrix element of C between plane-wave states is V_s delta_{P_f, P_i mod 2 pi/a} times a stripped amplitude C~ of the free leg momenta (one leg, say k_{n'}, is fixed by P_f = P_i). A monomial of c_0 with legs at positions x_1, ..., x_{n+n'} contributes the phase exp(i sum_l pm p_l . x_l); substituting the constrained momentum turns this into exp(i sum_{l free} pm p_l . (x_l - x_{n'})), so C~ is a trigonometric polynomial of degree <= D in each free variable a p_{l,j} (the translation sum produces the Kronecker delta and nothing else). C = 0 on the torus means C~ = 0 at every admissible point, i.e. on the grid (2 pi / L) Z^3 per free leg. A nonzero one-variable trigonometric polynomial of degree <= D has at most 2D zeros per period; a grid with L > 2D points per period therefore forces it to vanish identically; induction over the free leg variables (fix all but one, apply the one-variable statement, then the coefficients, themselves trigonometric polynomials in the remaining variables, vanish on the grid) gives C~ = 0 identically. The identity C~ = 0 is L-independent, so C = 0 on every torus with L > 2D, and the infinite-lattice operator has the same stripped amplitudes. (reviewer B's example: a centred bilinear of radius 2 with stripped symbol cos 4 theta - cos 2 theta vanishes on the L = 6 grid; here D = 4 and 2D = 8 > 6, so Lemma 0 does not apply to it, as it must not.) The converse (infinite lattice to torus) is the same statement read backwards. [R]

Remark. Lemma 0 is what makes "local on the lattice as such" a meaningful object: the first-order equation [H_0, Q_1] + [V, Q_0] = 0 below is an identity between trigonometric polynomials (with the stripped V amplitude, which is itself a trigonometric polynomial in each leg for both converters: the on-site W_0 has range 0, the filtered W_0 has range R_* of VERTEX_stress_v1), and may be evaluated at any real momenta, not only torus momenta. Here R is the range of the commutator, at most range(Q_1) + max(range(h_0), range(W_0)), and D <= 2R its support diameter. Equivalently one may simply assume conservation on every sufficiently large torus; all statements below are then unchanged.

### Lemma 1 (the O(U) on-shell element; reviewer A's first mechanism)

Let [H_0, Q_0] = 0 and let |i>, |f> be joint eigenstates: H_0 |i> = E_i |i>, Q_0 |i> = q_i |i>, likewise f. Then for any operator Q_1,

  <f| i[H_0, Q_1] |i> = i (E_f - E_i) <f| Q_1 |i>,      <f| i[V, Q_0] |i> = -i Delta q V_fi,   Delta q = q_f - q_i,

so the first-order equation [H_0, Q_1] + [V, Q_0] = 0 has the on-shell consequence

  (E_f = E_i and V_fi != 0)  ==>  q_f = q_i,                                                     (1.1)

equivalently P_E [V, Q_0] P_E = 0 for every energy E, i.e. the on-shell part of V commutes with Q_0. Conversely, if (1.1) holds for all pairs, some Q_1 solves the first-order equation (define <f|Q_1|i> = Delta q V_fi / (E_f - E_i) off shell and 0 on shell), but that Q_1 need not be local.

Proof. <f| V Q_0 |i> = q_i V_fi and <f| Q_0 V |i> = q_f V_fi since Q_0 is Hermitian with real eigenvalues; subtract. The H_0 line is the same with E. On shell the first vanishes, so the equation forces Delta q V_fi = 0. [R]

Consequences used later. (i) The first-order force i[H, Q] = U i([H_0, Q_1] + [V, Q_0]) + O(U^2) has the exact on-shell element -i U Delta q V_fi between normalizable degenerate free eigenstates (VERTEX_force_event_v1 (15)); this is reviewer A's statement and it holds for every Q_0 commuting with H_0, not only momenta. (ii) Condition (1.1) is necessary for conservation to all orders in U, because the order-U^1 equation is the same for every truncation order. (iii) For Q_0 = dGamma(q) with q band-scalar, q_i is the sum of the one-body eigenvalues q_A^{band}(p_l) of the occupied legs, so (1.1) reads, on every on-shell connected configuration,

  sum_{light legs} q_L^+(k_l) = sum_{heavy legs} q_H^+(p_l)        (positive-band legs; other bands analogous).   (1.2)

### Lemma 2 (band-scalar finite-range symbols are f + g h_0)

Let q_A(p) be a Hermitian 4x4 trigonometric-polynomial symbol with [q_A(p), h_{0,A}(p)] = 0 and spin-independent eigenvalues on each band. Then q_A = f_A 1_4 + g_A h_{0,A} with f_A, g_A real trigonometric polynomials, and conversely. The positive-band eigenvalue is q_A^+ = f_A + g_A E_A.

Proof. Where E_A(p) > 0 the band projectors are P_pm = (1 pm h_0/E)/2 and band-scalarity gives q = f^+ P_+ + f^- P_- = f 1 + g~ h_0 with f = (f^+ + f^-)/2 = tr(q)/4, a trigonometric polynomial, and g~ = (f^+ - f^-)/(2E). Heavy species: tr(beta (q - f))/4 = m g~, so g~ = tr(beta(q - f))/(4m) is a trigonometric polynomial. Light species (m = 0): tr(alpha_j (q - f))/4 = g~ sin(a p_j)/a =: t_j, trigonometric polynomials for j = 1,2,3. In the Laurent ring C[z_1^{pm1}, z_2^{pm1}, z_3^{pm1}] (a unique factorization domain), z_j = e^{i a p_j}, the elements s_j = (z_j - z_j^{-1})/2i are pairwise coprime (each is a unit times (z_j - 1)(z_j + 1), irreducibles in distinct variables). From t_1 s_2 = t_2 s_1 and coprimality, s_1 divides t_1, so g~ = t_1/s_1 is a Laurent polynomial wherever defined and extends to a trigonometric polynomial g; q = f + g h_0 then holds everywhere by continuity. Reality of f, g follows from Hermiticity (1 and h_0 are Hermitian and pointwise linearly independent). The converse is immediate. [R]

### Lemma 4 (geometry: an odd periodic function with gradient constant on energy surfaces vanishes)

Let ma < 1, I = (m, 1/a), and let Phi = q_L^o = f_L^o + g_L^o E_L (real-analytic on R^3 minus the discrete set (pi/a) Z^3 where d = 0; odd; 2 pi/a-periodic). Suppose that for every eps in I the gradient grad Phi is constant on the light valley-0 surface S_L(eps) = {k : |a k_j| < pi/2, E_L(k) = eps}. Then Phi = 0 identically, and f_L^o = g_L^o = 0.

Proof. Let O = {k : |a k_j| < pi/2, E_L(k) in I}, an open connected set (the region between two nested star-shaped surfaces). On O, grad Phi(k) = G(E_L(k)) for a function G: I -> R^3; G is real-analytic because grad Phi is and E_L has an analytic local inverse along any curve transversal to the surfaces. grad Phi is a gradient, so its curl vanishes: partial_i G_j(E) - partial_j G_i(E) = G_j'(E) partial_i E - G_i'(E) partial_j E = 0, i.e. G'(eps) x grad E_L(k) = 0 for every k in S_L(eps). The normals grad E_L(k) proportional to (sin 2 a k_1, sin 2 a k_2, sin 2 a k_3) at the two points k = kappa(1,1,1) and k = kappa(-1,1,1) of S_L(eps) (3 sin^2(a kappa) = a^2 eps^2, 0 < a kappa < pi/2, so sin 2 a kappa != 0) are not parallel, so G'(eps) = 0 for all eps in I, G = b is a constant vector, and Phi(k) = b.k + c on O. The function Phi(k) - b.k - c is real-analytic on the connected open set R^3 minus (pi/a) Z^3 and vanishes on O, hence everywhere there. Periodicity: for k and k + (2 pi/a) e_1 both off the discrete set, Phi agrees at both, so 2 pi b_1 / a = 0; likewise b_2 = b_3 = 0. Oddness: Phi(-k) = -Phi(k) gives c = -c = 0. So Phi = 0 off a discrete set, hence everywhere by continuity.

Finally f_L^o = -g_L^o |d| on R^3, so (f_L^o)^2 = (g_L^o)^2 |d|^2 as trigonometric polynomials (equal continuous functions). Suppose g_L^o is not identically zero; choose (theta_2, theta_3) with mu = sin^2 theta_2 + sin^2 theta_3 > 0 and g_L^o(., theta_2, theta_3) not identically zero (such pairs form a set of full measure). In C[z, z^{-1}], z = e^{i theta_1}, a^2 |d|^2 = mu + sin^2 theta_1 = -(z^4 - (4 mu + 2) z^2 + 1)/(4 z^2) has four distinct simple roots (z^2 = 2 mu + 1 pm 2 (mu^2 + mu)^{1/2}, two distinct positive values, each with two square roots), so it is squarefree; every irreducible factor of the left side has even multiplicity, while each of these four factors has odd multiplicity on the right. Contradiction; so g_L^o = 0 and then f_L^o = 0. [R]

The same argument applies to the heavy species with E_H = (m^2 + |d|^2)^{1/2} (analytic on all of R^3 since m > 0; squarefree factor mu' + sin^2 theta_1 with mu' = (ma)^2 + sin^2 theta_2 + sin^2 theta_3 > 0).
